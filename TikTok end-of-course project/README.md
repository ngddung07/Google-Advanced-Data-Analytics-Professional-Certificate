# Google Advanced Data Analytics Professional Certificate

This repository contains a collection of six end-of-course projects completed as part of the Google Advanced Data Analytics Professional Certificate.

Together, these projects provide a complete, rigorous data workflow: starting from data project proposals and Python fundamentals, moving through exploratory data analysis and statistical testing, and culminating in predictive modeling using regression and machine learning algorithms. They also demonstrate the core technical competencies required in each stage of the data analysis process:

- **Programming & Tools:** Python, Jupyter Notebooks.
- **Data Handling:** Pandas, NumPy, data profiling, and handling missing/anomalous data.
- **Math & Statistics:** Hypothesis testing, probability distributions, conditional expectation, and foundational calculus for optimization.
- **Visualization:** Matplotlib, Seaborn, Tableau.
- **Modeling:** Statistical modeling, regression diagnostics, and tree-based machine learning algorithms.

Nevertheless, this course highlights the importance of communication in aligning technical decisions with business objectives by translating the complex data science workflow for both business stakeholders and cross-functional teams, illustrated through the PACE (Plan, Analyze, Construct, Execute) strategy in every project:

- **Stakeholder Engagement:** Present findings with executive summaries, connect statistics in data with key performance indicators, and design intuitive dashboards and charts that allow non-technical audiences to quickly grasp the crucial details of an operation.
- **Technical alignment:** Perform structured data profiling, write clean, well-commented Python code, and provide concise methodology documentation to ensure data engineers and analysts accurately comprehend the workings in every stage of the data science process.

In addition, each project has its own dedicated folder with a README description of its objective, required skills and deliverables, an executive summary PDF as a thorough overview of its key findings, and a Python Jupyter notebook that annotates the code and analysis.
